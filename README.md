# LoliLand для Linux

Неофициальный установщик лаунчера LoliLand для Linux.

Официальный лаунчер выпускается только для Windows (`LoliLand.exe`), на Linux он сам по себе не запускается.
Этот скрипт ставит лаунчер, который работает на Linux напрямую, без Wine, Proton, виртуальных машин и других прослоек.

> Я не связан с администрацией LoliLand

Версия для macOS: [liraquo/loliland-mac](https://github.com/liraquo/loliland-mac).

## Быстрый старт

Откройте терминал и выполните:

```sh
curl -fLO https://raw.githubusercontent.com/liraquo/loliland-linux/main/install-loliland.sh
bash install-loliland.sh
```

Дождитесь сообщения «Готово». LoliLand появится в меню приложений, в разделе «Игры».
Скачанный `install-loliland.sh` после этого можно удалить.

- Приложение: `~/.local/share/loliland-launcher/`
- Данные лаунчера и логи: `~/.local/share/loliland/` (лог: `linux-app.log`)
- Ярлык: `~/.local/share/applications/loliland.desktop`

Для обновления запустите установщик ещё раз. Для удаления удалите эти три пути.

## Как это работает

### Почему лаунчер можно запустить нативно

`LoliLand.exe` — это не сам лаунчер, а небольшой загрузчик для Windows. При запуске он:

1. запрашивает у сервера LoliLand манифест (описание актуальных файлов);
2. скачивает Java для Windows и сам лаунчер, файл `launcher.jar`;
3. запускает `launcher.jar` через эту Java.

Сам лаунчер написан на Java, а Java-программы работают на любой системе, где есть подходящая Java. Поэтому Windows-загрузчик не нужен: скрипт делает то же, что и он, только скачивает ту же версию Java для Linux.

### Что делает скрипт по шагам

1. **Проверки перед началом.** Скрипт убеждается, что запущен на Linux не от root, что все нужные утилиты на месте, и определяет архитектуру (x86_64 или aarch64).
2. **Лаунчер.** Скачивает манифест с `klauncher.loliland.pro` и сам [`launcher.jar`](https://klauncher.loliland.pro/api/updater/load/launcher), тот же файл, что получает Windows-загрузчик, и проверяет его.
3. **Java.** Скачивает JBR (JetBrains Runtime с встроенным браузером JCEF, на нём сделан интерфейс лаунчера) с официального сервера JetBrains и проверяет его.
4. **Сборка.** Создаёт скрипт запуска, достаёт иконку из самого лаунчера и добавляет ярлык в меню приложений.

### Безопасность

- Скрипт не требует прав администратора и ничего не меняет в системе. Все файлы ложатся в `~/.local/share`.
- Файлы скачиваются только по HTTPS и только из двух источников: сервер LoliLand и сервер JetBrains.
- Java проверяется по SHA-512 от JetBrains. Для лаунчера сервер LoliLand публикует только размер, поэтому проверяются размер, целостность архива и наличие главного класса.
- Новая версия собирается во временной папке и заменяет старую только после всех проверок.
- Скрипт короткий, его можно прочитать самому или проверить нейронкой.

## Требования

`bash`, `curl`, `tar`, `unzip` и стандартные coreutils. Если чего-то нет, скрипт скажет, что поставить. Например, на Debian/Ubuntu `unzip` ставится командой `sudo apt install unzip`.

## Если что-то пошло не так

| Сообщение | Что делать |
|---|---|
| «Не удалось получить манифест» или «Не удалось скачать» | Проблема с интернетом, или сервер LoliLand недоступен. Попробуйте позже или с VPN. |
| «SHA-512 не совпадает» или «Размер не совпадает» | Файл скачался не полностью. Запустите установку ещё раз. |
| «LoliLand сейчас запущен» | Закройте лаунчер и игру, затем повторите установку. |
| Лаунчер открывается и сразу закрывается | Посмотрите последние строки `~/.local/share/loliland/linux-app.log`, там будет ошибка. Её стоит приложить к issue. |

Если не помогло, [создайте issue](../../issues) и приложите текст ошибки из терминала или лог.

Я не разработчик проекта и не администратор, работа отдельных игровых сборок на Linux не гарантируется.
